# 交互式shell脚本工具
> Debian系、root用户
## 示例

```sh
> ---  当前目录: [ /root ] ---- < v:xxx

当前菜单: 首页 

1: 软件管理           2: 网络管理

3: 系统管理           4: 服务管理

5: docker管理         6: 磁盘管理

7: 文件管理           8: 其他工具

0: 首页 b: 返回 q: 退出 s:脚本设置

请输入命令号(0-8): 

```


## 安装


### 一键安装(推荐)


```sh
wget -N  http://raw.githubusercontent.com/sshpc/s/main/s.sh && chmod +x s.sh &&  bash s.sh
```

> 再次执行只需要输入 “s” 

```sh
 root@server:~#  s
```
